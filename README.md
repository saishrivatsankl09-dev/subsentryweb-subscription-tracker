# subsentryweb-subscription-tracker
A web-based subscription tracking and management system built using HTML, CSS, JavaScript, and Firebase.
A Smart Subscription Tracking and Management System.

## Live Demo
https://subsentry-5e9cb.web.app

## Features
- Add, edit, and delete subscriptions
- Track upcoming renewals
- Calculate monthly subscription expenses
- Firebase authentication
- Cloud Firestore synchronization

## Technologies
HTML, CSS, JavaScript, Firebase Authentication,
Cloud Firestore, Firebase Hosting
